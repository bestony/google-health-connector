# GHealth Connector by StillWarm.app — 产品描述

> 自用速查。价格以 `src/lib/plans.ts` 为准，改价改那里，本文跟着更新。

**一句话**：把你的 Google Health 数据接到任意 AI 助手上，用聊天的方式问自己的健康数据。

## 做什么

Google 登录授权一次，拿到一个 MCP 地址和一个 API Key。粘到 Claude、ChatGPT、Grok
或任何支持 MCP 的客户端里，助手就能读你的睡眠、运动、心率、营养等数据并回答问题。

数据实时从 Google Health 读取，服务端不存副本，随时可以在 Google 账号设置里收回授权。

## 给谁用

- **主要**：用 Google Health 记录数据（Pixel Watch / Fitbit / 安卓手机等）、
  同时天天用 AI 助手的个人用户。
- **其次**：想给自己的 Agent 加上健康数据、又不想自己写一遍 Google OAuth 的开发者。
- **不面向**：医院、保险、雇主。这是个人查自己数据的自助产品，不转售、不共享、不拿来训练。

## 定价

| 方案 | 价格 | 包含 |
| --- | --- | --- |
| Free | $0，不需要信用卡 | 12 类健康数据实时读取、90 天历史、MCP 端点 + 1 个 API Key |
| Pro | **$9.99/年**，或 **$1.99/月**（年付省 58%） | Free 全部功能 + 不限时间的完整历史、跨年长周期趋势分析、优先支持 |

年付是主推价：一年扣一次款比扣十二次少踩过期卡，且支付渠道的固定手续费占 $1.99 的
比例远高于占 $9.99 的比例——两档之间的差价主要是手续费，不是毛利。

订阅自动续费，可随时取消，取消后当期结束生效。退款条款见 `src/lib/legal.ts` 的
`LEGAL_BILLING`：新订阅 7 天全额退、年费 30 天内可申请退、连续故障满 72 小时按比例退。

## 关键功能

1. 一次授权，12 类数据分类勾选，读 / 写权限独立授予
2. 开放 MCP 协议，不绑定单一厂商
3. 实时读取，服务端不存健康数据
4. API Key 自助创建、轮换、吊销，带频率限制（防 Agent 死循环）
5. 随时在 Google 账号里撤销授权；删号请求 30 天内处理

## 典型用例

- "我这周睡眠和上个月比怎么样？"
- "我的静息心率比去年真的变高了吗？"（Pro，跨年对比）
- "睡不够 6 小时的那几周，我跑步是不是变慢了？"（跨品类关联）
- "把我最近 30 天的运动和饮食整理成一段话，我要给医生看。"
